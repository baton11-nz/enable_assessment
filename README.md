# Requirement

Automation: Automate the user journey below using your preferred tech stack (programming
language, framework, tooling, etc.). Then, ensure that the below buttons exist in the ‘Your Cart’
page.
a. Remove (per product)
b. Continue Shopping
c. Checkout
User journey: Login > Open a product > Add to cart > Go back to products page > Open another
product > Add to cart > View Cart

## Covered journey

1. Login with `standard_user`
2. Open "Sauce Labs Backpack" item
3. Add item to the cart
4. Open left navigation
5. Click All Items to return to Products page
6. Open "Sauce Labs Bike Light" item
7. Add item to the cart
8. Click on cart icon to checkout
9. Verify a Remove button exists for each product
10. Verify Continue Shopping button exists
11. Verify Checkout button exists
